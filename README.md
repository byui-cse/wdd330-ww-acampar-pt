# BYU-Pathway Worldwide Online

## WDD 330 - Desenvolvimento Frontend para Web II

### ⛺ Código Inicial do Acampar

- Este repositório é o ponto de partida do projeto da aplicação web Acampar do WDD 330. O repositório contém branches que são pontos de controle das atividades em equipe e individuais ao longo do curso.

- <https://byui-cse.github.io/wdd330-ww-course-pt/week01/team.html>

### Pré-requisitos

- Você precisa ter o Node instalado para executar os comandos a seguir.
[WDD 330 Configurar o Node e o NPM](https://byui-cse.github.io/wdd330-ww-course-pt/intro/setup-node-npm.html)

### Comandos Comuns do Fluxo de Trabalho

- `npm run lint` para executar o ESLint no seu código e encontrar erros.
- `npm run format` para executar o Prettier e formatar seu código automaticamente.
- `npm run start` inicia um servidor local que se atualiza a cada mudança no JS ou no CSS/SCSS.
- `npm run build` para gerar os arquivos finais quando você estiver pronto(a) para entregar.
